# Excalidraw Specification - Side-by-Side Visual Split

## Visual Directives
- **Layout:** Canvas split vertically into two equal halves by a dashed gray line.
- **Left Column (Legacy / Problematic Approach):**
  - Red Header / Subtle Gray background.
  - Sequential, slow single-step arrows.
- **Right Column (Modern / Optimized Approach):**
  - Green Header / Light Green tint background.
  - Parallel, simultaneous arrows demonstrating efficiency gains.
